### Анализ системы и планирование логирования

Системы для логирования:
- Internet Shop
- CRM System
- MES System
- Message Queue (RabbitMQ)
- 3D File Storage

Список логов уровня INFO:

1. Internet Shop:
- Создание заказа (время, ID покупателя, номер заказа)
- Загрузка 3D-модели (время, ID покупателя, размер файла)
- Изменение статуса заказа

2. CRM System:
- Подтверждение заказа производством
- Изменение статуса заказа
- Взаимодействие с внешними API

3. MES System:
- Старт производства заказа
- Завершение производства
- Упаковка заказа
- Отправка заказа
- Расчет стоимости изделия

Уровни логирования:
- INFO: Штатные операции
- WARN: Предупреждения, нестандартные ситуации
- ERROR: Критические ошибки
- DEBUG: Детальная информация для диагностики

### Мотивация

Технические метрики:
- Сокращение времени диагностики проблем на 60%
- Повышение отказоустойчивости системы
- Улучшение качества мониторинга производственных процессов

Бизнес-метрики:
- Снижение числа необоснованных жалоб клиентов на 40%
- Сокращение времени реакции службы поддержки
- Возможность проведения аналитики бизнес-процессов

Приоритезация систем для логирования:

| Система | Приоритет | Обоснование |
|-|-|-|
| MES | Высокий | Критические проблемы с производством и задержками |
| CRM | Высокий | Взаимодействие с клиентами и подтверждение заказов |
| Internet Shop | Средний | Первичные этапы работы с заказом |

3. Предлагаемое решение

Компоненты:
- ELK Stack (Elasticsearch, Logstash, Kibana)
- Filebeat для сбора логов
- OpenTelemetry для распределенного трейсинга

Архитектура:
- Централизованное хранение логов
- Агенты Filebeat на каждом сервере
- Логстеш для парсинга и трансформации
- Эластик для индексации и хранения
- Кибана для визуализации

4. Политика безопасности и хранения

Безопасность:
- Маскирование персональных данных
- Шифрование логов
- Ролевой доступ (администраторы, разработчики)
- Многофакторная аутентификация

Хранения логов:
- Отдельный индекс для каждой системы
- Хранение 90 дней
- Максимальный размер индекса 500 ГБ
- Ротация индексов еженедельно

5. Система анализа логов

Алертинг:
- Превышение времени производства заказа
- Резкое увеличение числа ошибок
- Аномальная активность в системе

Обнаружение аномалий:
- Машинное обучение Elasticsearch
- Выявление нехарактерных паттернов
- Автоматическое обнаружение DDoS-атак
- Корреляционный анализ событий

# Критерии для выбора технологии для работы с логами

| Критерий | ELK Stack | OpenSearch | Splunk | Fluentd + ClickHouse | Grafana Loki |
|----------|-----------|------------|--------|---------------------|--------------|
| Лицензия | Elastic License (ограничения на коммерческое использование) | Apache License 2.0 (полностью открытая) | Проприетарная (дорогая) | Apache 2.0 + Apache 2.0 (открытые) | Apache 2.0 (открытая) |
| Стоимость владения | Средняя (бесплатная базовая версия, платные расширенные функции) | Низкая (полностью бесплатная) | Высокая (лицензирование по объему данных) | Низкая (только инфраструктура) | Низкая (бесплатная с Grafana Cloud опционально) |
| Производительность и масштабируемость | Хорошая (до ~TB в день) | Хорошая (форк Elasticsearch) | Отличная (оптимизирована для больших объемов) | Отличная (ClickHouse очень быстрый) | Хорошая (оптимизирована для логов) |
| Простота развертывания и настройки | Сложная (много компонентов: Elasticsearch, Logstash, Kibana) | Сложная (аналогично ELK) | Простая (all-in-one решение) | Средняя (настройка двух систем) | Простая (минималистичная архитектура) |
| Возможности поиска и анализа | Отличные (мощный поисковый движок, множество агрегаций) | Отличные (идентичны Elasticsearch) | Превосходные (SPL язык, ML возможности) | Хорошие (SQL запросы, быстрая аналитика) | Базовые (LogQL, фокус на просмотре логов) |
| Интеграции и экосистема | Обширная (множество плагинов и интеграций) | Растущая (совместимость с Elasticsearch) | Очень обширная (enterprise интеграции) | Средняя (Fluentd имеет много плагинов) | Хорошая (интеграция с Prometheus, Grafana) |
| Удобство использования | Хорошее (Kibana интуитивен) | Хорошее (OpenSearch Dashboards) | Отличное (продуманный UI/UX) | Среднее (требует знания SQL) | Хорошее (знакомый интерфейс Grafana) |
